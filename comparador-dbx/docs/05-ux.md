# 05 · Experiencia de usuario

El usuario es un **auditor no técnico**. Si la interfaz exige muchos pasos, dejará de usar la aplicación.
Regla de diseño: **arrastrar → revisar lo que el sistema propuso → procesar → elegir → descargar**.

## Pantalla 1 — Carga
- Zona de arrastre grande: *"Arrastra aquí tus normativas y manuales (PDF)"*. Acepta varios archivos a la vez.
- Debajo, tabla con una fila por archivo:
  - nombre del archivo
  - **tipo**: desplegable *Normativa* / *Manual de control* (único campo obligatorio)
  - campos opcionales en línea: entidad emisora, título oficial, libro, título, capítulo, número de norma, fecha de vigencia
  - estado
- Al soltar los archivos, el sistema llena tipo y metadatos con indicador sutil de **"sugerido"**. Si la confianza es baja, el tipo queda **vacío** y la fila se resalta.
- **Procesar** se habilita solo cuando todas las filas tienen tipo.
- Botón secundario **"Cargar ejemplo"**.

## Pantalla 1b — Procesamiento
- Estado por documento: `En cola → Extrayendo → Seccionando → Indexando → Listo` o `Error` con mensaje claro.
- Barra global. Los documentos listos se pueden ver mientras otros siguen en cola.

## Pantalla 2 — Selector dual
- Dos paneles lado a lado: **Normativas** (izquierda) y **Manuales de control** (derecha).
- Cada panel es un árbol: `Documento → nivel jerárquico (libro/título/capítulo/sección) → artículo o subsección`. Nodos colapsables con casilla.
- Cada hoja muestra identificador + primeras ~120 letras. Clic o hover: vista previa del texto literal y página.
- Secciones con `seccionado_incierto` llevan ícono de advertencia: *"Esta sección se detectó por longitud; revísala"*.
- Pie: *"Vas a comparar 42 artículos de 2 normativas contra 37 secciones de 1 manual"* + botón **Comparar**.

## Pantalla 3 — Resultados
- Resumen: conteo por marca (A, L, R, X, P) y controles sin base normativa.
- Tabla filtrable por marca con conmutador *Ver por artículo (vía 1)* / *Ver por control del manual (vía 2)*.
- Detalle expandible: texto literal de la norma, cita del manual, comentario, confianza.
- Caja editable con el borrador de conclusión: *"Propuesta generada automáticamente — revísala antes de firmar"*.
- Botón **Descargar papel de trabajo (.xlsx)**.

## Mensajes de error
| Situación | Mensaje al auditor |
|---|---|
| PDF escaneado | "Este documento parece ser una imagen escaneada. Por ahora solo podemos leer PDFs con texto seleccionable." |
| Excede límites | "El archivo supera el máximo de 100 páginas o 20 MB. Divídelo o consulta con el equipo de soporte." |
| Gateway no disponible | "No pudimos conectarnos al servicio de análisis. Intenta de nuevo en un momento." |
| Sección sin texto | "No encontramos texto en esta sección; se omitirá del análisis." |
| Sesión perdida | "La sesión se reinició y los documentos ya no están disponibles. Vuelve a cargarlos o usa el ejemplo." |

Nunca mostrar trazas técnicas. Cada error lleva un código corto para correlacionar con logs (ej. `ERR-EXT-002`).

Códigos de la implementación (los mensajes al auditor van en lenguaje de negocio):
| Código | Cuándo |
|---|---|
| `ERR-ING-001` / `002` / `003` | PDF escaneado / fuera de límites / no se pudo abrir |
| `ERR-EXT-001` / `002` / `003` | falla de la extracción / vence el tiempo / sin texto |
| `ERR-SEC-001` | un bloque de texto supera el tope (`SECCION_BLOQUE_MAX`) |
| `ERR-IDX-001` | el modelo devolvió vectores no válidos (NaN, dimensión distinta, respuesta corta) |
| `ERR-LLM-*`, `ERR-CFG-001` | proveedor de modelos: no responde, saturado, o mal configurado |
