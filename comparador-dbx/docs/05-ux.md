# 05 · Experiencia de usuario

El usuario es un **auditor no técnico**. Si la interfaz exige muchos pasos, dejará de usar la aplicación.
Regla de diseño: **arrastrar → revisar lo que el sistema propuso → procesar → elegir → descargar**.

## Línea de cuenta (todas las pantallas)
Bajo la cabecera, texto pequeño y neutro (RF-24): **«{usuario}** · Tus documentos procesados se conservan hasta {retencion_horas} horas sin actividad o hasta que la aplicación se reinicie. Los PDF no se guardan.». `usuario` es el correo de la cuenta o «Sesión local»; las horas salen de `GET /api/session`, no de un texto fijo.

## Pantalla 1 — Carga
- Zona de arrastre grande: *"Arrastra aquí tus normativas y manuales (PDF)"*. Acepta varios archivos a la vez.
- Debajo, tabla con una fila por archivo:
  - nombre del archivo
  - **tipo**: desplegable *Normativa* / *Manual de control* (único campo obligatorio)
  - campos opcionales en línea: entidad emisora, título oficial, libro, título, capítulo, número de norma, fecha de vigencia
  - estado
- Al soltar los archivos, el sistema llena tipo y metadatos con indicador sutil de **"sugerido"**. Si la confianza es baja, el tipo queda **vacío** y la fila se resalta.
- **Procesar** se habilita solo cuando todas las filas tienen tipo.
- Contador **«{n} de {max} documentos»** (los documentos con error no cuentan). Al llegar al tope la zona de carga se desactiva: *«Llegaste al máximo de {max} documentos. Quita alguno de la lista para agregar otro.»*
- Cada fila tiene **Quitar** (sin confirmar si no está procesado; con confirmación si ya lo está, porque descarta la comparación vigente). Las filas con error añaden **Reintentar** sin volver a subir el PDF. Con un proceso en curso, Quitar queda desactivado.
- **Multicarga:** desde Selección se vuelve aquí con «Agregar documentos»; lo procesado y las marcas se conservan.
- Botón secundario **"Cargar ejemplo"** (no duplica el ejemplo si ya está cargado y respeta el tope). «Borrar todo y empezar de nuevo» pide confirmación.
- Al terminar cada procesamiento aparece el **aviso de PDF no guardado** (`docs/ux/aviso-pdf-no-guardado.md`) con la casilla «No volver a mostrar en esta sesión».

## Pantalla 1b — Procesamiento
- Estado por documento: `En cola → Extrayendo → Seccionando → Indexando → Listo` o `Error` con mensaje claro.
- Barra global. Los documentos listos se pueden ver mientras otros siguen en cola.
- **Progreso en vivo (RF-20, `docs/ux/mejora-experiencia-v1.md`):** tres etapas (Leyendo → Armando el índice → Preparando la búsqueda); por documento, una celda por página (miniatura de la página ya leída, pulso en la tanda en lectura), «página N de M», tiempo transcurrido, estimado con rango y «última novedad hace N s»; al terminar el seccionado, los conteos reales del índice. Botón **Cancelar** (RF-21).

## Pantalla 1b — Retomar el avance
- Si al abrir (o recargar) la aplicación el servidor informa un `trabajo_activo`, se entra directo a la vista de avance con *«Este proceso sigue en marcha desde antes. Puedes esperar aquí o volver más tarde.»*. Mientras haya un trabajo activo no se puede lanzar otro (*«Ya hay un proceso en marcha con tu cuenta. Espera a que termine.»*).

## Pantalla 2 — Selector dual
- Dos paneles lado a lado: **Normativas** (izquierda) y **Manuales de control** (derecha).
- Cada panel es un árbol: `Documento → nivel jerárquico (libro/título/capítulo/sección) → artículo o subsección`. Nodos colapsables con casilla.
- **El árbol es el índice del documento:** abierto hasta el artículo si el documento tiene ≤ 150 nodos (si no, hasta el nivel 2); cada rama muestra `marcados/total` y la página; buscar, expandir/contraer todo y «solo marcados»; casilla tri-estado; teclado según el patrón ARIA *tree* (↑↓, →, ←, Espacio, `*`).
- Cada hoja muestra identificador + primeras ~120 letras. Clic o hover: vista previa del texto literal y página.
- Secciones con `seccionado_incierto` llevan ícono de advertencia: *"Esta sección se detectó por longitud; revísala"*.
- Las secciones **no comparables** (carátula, preámbulo, índice, control de versiones, anexos…) aparecen **atenuadas, con la casilla vacía y su motivo** ("anexo", "índice"…). Un aviso dice *"Se excluyeron 14 secciones que no son cuerpo del manual"*; el auditor puede marcarlas de nuevo o excluir otras.
- Si hay más de un manual procesado, un aviso fijo: *«La comparación usa un manual a la vez. Elige en cuál trabajar.»*; cambiar de manual con marcas pide confirmación.
- Botón **«Agregar documentos»** (vuelve a Carga sin perder marcas).
- Pie: *"Vas a comparar 42 artículos de 2 normativas contra 37 secciones de 1 manual"* + botón **Comparar**.

## Pantalla 2b — Comparación en curso
- Fase y «par X de Y»; aviso «Esperando al servicio de IA… se reanuda en N s» si el proveedor limita el uso.
- **Ahora se analizan** (hasta `LLM_CONCURRENCY` pares): fragmento literal de la norma y del manual, página, similitud y vía que lo encontró.
- **Últimos veredictos**: cobertura (icono + palabra), confianza, citas verificadas / por revisar y, bajo demanda, el comentario del modelo (texto plano). Conteos provisionales por par, rotulados como tales (las marcas A/L/R/X/P se calculan al final).
- Nota fija: *«No mostramos razonamiento: el modelo solo entrega un veredicto con citas»*. Botón **Cancelar**.

## Pantalla 3 — Resultados
- Resumen: conteo por marca (A, L, R, X, P) y controles sin base normativa.
- Tabla filtrable por marca con conmutador *Ver por artículo (vía 1)* / *Ver por control del manual (vía 2)*.
- Detalle expandible: texto literal de la norma, cita del manual, comentario, confianza.
- Caja editable con el borrador de conclusión: *"Propuesta generada automáticamente — revísala antes de firmar"*.
- Botón **Descargar papel de trabajo (.xlsx)**. Junto a él: **«Cambiar la selección y comparar de nuevo»** y **«Agregar documentos»**, y la nota *«Al comparar de nuevo, este resultado se reemplaza. Lo único que se conserva es el papel de trabajo que descargues.»*

## Panel Ajustes (RF-19)
- Entrada en la barra superior («Ajustes», junto a Carga · Selección · Resultados); no interrumpe el flujo y se puede abrir en cualquier momento.
- Parámetros con **nombre de negocio**, una línea de ayuda («más bajo trae más candidatos y más ruido»), control numérico con su rango, el valor por defecto visible y «Restablecer». Los avanzados van plegados en «Avanzado» con un aviso de que cambiarlos afecta la calidad o el costo.
- «Guardar» aplica los valores a **esta sesión** (expiran con ella). «Exportar ajustes» baja un `.json` y «Importar ajustes» lo carga: así se reutilizan entre sesiones sin que el servidor guarde nada. El servidor valida rangos y descarta claves desconocidas.
- Cambiar un ajuste **no** reprocesa documentos ni rehace comparaciones ya hechas; aplica a la próxima comparación. Los resultados indican «Ajustes usados» para poder reproducirlos.

## Mensajes de error
| Situación | Mensaje al auditor |
|---|---|
| PDF escaneado | "Este documento parece ser una imagen escaneada. Por ahora solo podemos leer PDFs con texto seleccionable." |
| Excede límites | "El archivo supera el máximo de 250 páginas o 20 MB. Divídelo o consulta con el equipo de soporte." |
| Gateway no disponible | "No pudimos conectarnos al servicio de análisis. Intenta de nuevo en un momento." |
| Sección sin texto | "No encontramos texto en esta sección; se omitirá del análisis." |
| Sesión perdida (`ERR-SES-001`) | "Se perdió lo que tenías cargado. La aplicación se reinició o pasó el plazo de conservación; carga de nuevo tus PDF." Con `GET /api/session` el servidor abre una sesión nueva (`sesion_nueva`) y la persona puede seguir |
| Sin identidad (`ERR-SES-003`) | "No pudimos identificar tu cuenta. Vuelve a abrir la aplicación desde Databricks." |
| Origen no válido (`ERR-SEG-001`) | "No pudimos validar el origen de la solicitud. Recarga la página e inténtalo de nuevo." |
| Tope de documentos (`ERR-ING-004`) | "Llegaste al máximo de {max} documentos. Quita alguno de la lista para agregar otro." |
| Tipo de un documento ya procesado (`ERR-DOC-003`) | "Este documento ya se procesó. Para cambiar su tipo, quítalo y cárgalo de nuevo." |
| Quitar con proceso en curso (`ERR-DOC-006`) | "Espera a que termine el proceso en curso o cancélalo antes de quitar documentos." |
| PDF ya no guardado (`ERR-DOC-001`) | "El PDF de «{nombre}» ya no está en la aplicación; solo se conserva su contenido preparado." |
| Otro proceso en marcha (`ERR-JOB-002`) | "Ya hay un proceso en marcha con tu cuenta. Espera a que termine." |

Nunca mostrar trazas técnicas. Cada error lleva un código corto para correlacionar con logs (ej. `ERR-EXT-002`).

Códigos de la implementación (los mensajes al auditor van en lenguaje de negocio):
| Código | Cuándo |
|---|---|
| `ERR-ING-001` / `002` / `003` | PDF escaneado / fuera de límites / no se pudo abrir |
| `ERR-EXT-001` / `002` / `003` | falla de la extracción / vence el tiempo / sin texto |
| `ERR-EXT-005` | el auditor canceló la lectura del documento (no es un error del documento: vuelve a «cargado» y se puede reintentar) |
| `ERR-SEC-001` | un bloque de texto supera el tope (`SECCION_BLOQUE_MAX`) |
| `ERR-IDX-001` | el modelo devolvió vectores no válidos (NaN, dimensión distinta, respuesta corta) |
| `ERR-LLM-*`, `ERR-CFG-001` | proveedor de modelos: no responde, saturado, o mal configurado |
